# Amazon Sales Data Analysis

## Project Overview
This project analyzes an Amazon sales dataset to understand product trends, pricing patterns, and customer behavior using Python.

## Dataset
- Source: Kaggle
- Includes product name, category, price, ratings, and reviews

## Tools Used
- Python
- Pandas
- Matplotlib


##  Analysis Performed
- Top categories
- Most reviewed products
- Price vs rating
- Rating distribution

## Key Insights
- Electronics accessories dominate the dataset
- Few products have very high review counts
- Price does not strongly affect ratings
- Most products have good ratings


##  How to Run
1. Open the notebook
2. Run all cells
3. View results
